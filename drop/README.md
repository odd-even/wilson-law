# Drop folder — full-size screenshots

**Put original screenshots here** (Desktop exports, Finder files — not chat pastes).

Chat compresses images. Files dropped in this folder stay full resolution.

## How to use

1. Copy or drag screenshots into this folder (`drop/`)
2. Tell me in chat: **“process drop”** (or anything that means process new assets)
3. I will:
   - Open each file and identify what it is
   - Rename to `YYYY-MM-DD_short-description.ext`
   - Move it into the right `_assets/` folder
   - Log it in `activity-log.md` + `_assets/README.md`
   - Wire it into the HTML report when it belongs there
4. This folder should end up empty (or only this README)

## Destination folders

| If the screenshot is… | It goes to |
|------------------------|------------|
| Google Business Profile / Maps listing | `_assets/gbp/` |
| Google reviews / reply UI | `_assets/reviews/` |
| Squarespace (pages, SEO, traffic, AI Visibility) | `_assets/squarespace/` |
| Google Search Console | `_assets/gsc/` |
| Google Analytics | `_assets/ga4/` |
| Vendor / tool invoices or dashboards | `_assets/vendors/` |
| Anything else | `_assets/misc/` |

## Tips

- Keep the original filename if you want — I’ll rename.
- PNG or JPEG is fine; prefer the largest export you have.
- Several files at once is fine.
- Optional: prefix with a hint, e.g. `gbp-hours.png` or `gsc-sitemaps.png`, to speed filing.
