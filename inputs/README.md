# Inputs drop folder

Text notes and pasted lists go here. **Screenshots and image/PDF exports go in `_assets/`** (not here).

Suggested filenames:
- `vendors.md` — tools, costs, who owns them
- `gbp-notes.md` — optional text companion to `_assets/gbp/` screenshots
- `squarespace-notes.md` — optional companion to `_assets/squarespace/`
- `gsc-notes.md` — optional companion to `_assets/gsc/`
