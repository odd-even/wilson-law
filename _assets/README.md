# Assets

Screenshots, exports, and evidence used for audits and monthly reports.

## Drop full-size screenshots here first

**Inbox:** [`../drop/`](../drop/) — put original Desktop/Finder screenshots there, then say **“process drop”** in chat.

I’ll rename, file into the folders below, log them, and update the report. Prefer this over pasting into chat (chat downsizes images).

**Rule:** Every filed asset gets logged in `activity-log.md` and referenced in findings / monthly reports.

## Subfolders

| Folder | Put here |
|--------|----------|
| `drop/` → see repo root `drop/` | Inbox only — do not leave files here long-term |
| `gbp/` | Google Business Profile (info, categories, services, hours, photos, dashboard) |
| `reviews/` | Review list, individual reviews, reply UI |
| `squarespace/` | Pages list, SEO settings, domains, analytics, AI Visibility |
| `gsc/` | Search Console (coverage, sitemaps, queries, experience) |
| `ga4/` | Analytics reports / traffic screenshots |
| `vendors/` | Invoices, dashboards, tool UIs for SEO/review vendors |
| `reports/` | Exported PDFs or images of finished monthly reports (optional) |
| `misc/` | Anything else (Maps SERP, competitor, email confirmations) |

## Naming convention

```
YYYY-MM-DD_short-description.ext
```

Examples:
- `2026-08-25_gbp-info.png`
- `2026-08-25_gbp-reviews-overview.png`
- `2026-08-25_sqsp-pages-list.png`
- `2026-08-25_gsc-sitemaps.png`

Optional month subfolders later if volume grows (`gbp/2026-08/…`). For now, flat + dated filenames is enough.
